# Reliability brief

## The problem

The business needed a reliable web page that could remain available even if there were failures or changes in demand. 
The solution needed to be simple, dependable, and able to serve users without requiring constant maintenance.

## What I'd build

I would use Amazon S3 to store and host the website files because it provides durable and reliable storage without requiring us to manage servers. 
If the website needed better performance for users in different locations, additional AWS services could be added later, but S3 provides a simple and scalable starting point. 
This approach keeps the solution easy to manage while ensuring that the website remains available.

## What it costs

The monthly cost would depend mainly on the amount of data stored, the number of requests, and the amount of traffic the website receives. 
For a small website with low traffic, the cost would be relatively low, while higher traffic would increase storage and request costs over time.
